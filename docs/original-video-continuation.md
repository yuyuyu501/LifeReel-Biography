# Original Media Continuation

Seedance continuation must reuse provider originals, not locally extracted or
resized frames. The provider trusts supported originals generated by the same
account within 30 days. Output moderation still applies.

## New Productions

- Every segmented submission requests `return_last_frame: true`.
- Original MP4 bytes and provider-returned tail bytes are saved separately from
  the normalized, assembled chapter. Tail files are content-addressed under
  `LifeReel-Biography/generated/<tenant>/<run>/originals/`.
- The next segment sends the unchanged tail as `first_frame`. No screenshot,
  JPEG conversion, resizing, or watermark editing is performed.
- Task ID, model, generation timestamp, content hash, and a credential-scope hash
  are retained. A credential change requires task ownership revalidation.
- Missing original timestamps, expired originals, or altered files fail closed.

## Legacy Recovery

`POST /v1/production/runs/<run_id>/continuation` repairs legacy failures caused
by locally extracted reference frames. It uses the existing production execution
lock, validates the original before reserving a budget, and queues only unfinished
segments. No completed clip is regenerated.

The original task is queried with current credentials and its MP4 is compared
byte-for-byte to the retained clip. If a provider tail exists, it is saved and
used. Otherwise, the original MP4 is sent as `reference_video` with instructions
to extend its ending and output only new content. Signed storage URLs are created
per request and never included in public manifests.

The repair cannot be repeated after an original is rejected. Ordinary blind
retries remain blocked. No automatic switch to another image or provider occurs.
Provider receipts and the existing exactly-once billing settlement are preserved.

For Mini 720p, standard provider rates are CNY 23/million tokens without video
input and CNY 14/million with video input. Submitted receipts persist this mode;
settlement uses `usage.completion_tokens` (already includes reference-video usage)
at the matching standard rate times 1.5. Do not add input-video duration again or
apply the no-video rate to video-extension receipts.

Legacy recovery requires the provider task to remain queryable (currently 7 days)
and its original download to remain accessible. New saved originals can be reused
within the provider's 30-day trust period. Storage retention does not extend trust.

Video extension may repeat a short tail or vary movement/audio. Validate the join,
duration, dialogue, and audio before treating successful generation as a finished
editorial result. Do not trim reference originals; edit only the final assembly.
