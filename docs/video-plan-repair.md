# 分镜校验与定向修正

## 保留的规则

分段数为 ceil(预估秒数 / 15)，再均匀分配整数秒数。22 秒为 11+11，
31 秒为 11+10+10，40 秒为 14+13+13。没有改为优先填满 15 秒。
旁白仍须按原顺序完整保留，包括标点，忽略空白；不会为了通过校验删改事实。

## 失败分类

校验区分 JSON 解析、字段结构、章节顺序、分段数量、分段时长及旁白一致性。
时长与段数错误记录实际值和期望值；旁白错误只在诊断摘要中记录首个差异位置和长度，
不将家庭隐私文本放入公开响应或普通应用日志。

每次失败先保存诊断，再将具体 issues 和上一次返回反馈给 AI，要求输出修正后的完整
JSON。每次执行最多 3 次分镜调用；网络或计费等请求异常立即停止，不作为格式问题重发。
已有单次请求对不支持 JSON 模式的 HTTP 400 降级行为保留。
修正请求仅携带上一次返回，最多 24000 字符，避免递归累积上下文与费用。
这些调用仍使用原来的 token 用量记录与结算，不免费重试，也不新增无限后台重试。

## 私有诊断

使用原私有存储，不创建公共访问端点。文件位于：

`LifeReel-Biography/diagnostics/{tenant_id}/{run_id}/{diagnostic_id}/attempt-{1..3}.json`

每份包含校验摘要和失败返回，返回最多保留 64000 字符，并记录是否截断。
原剧本依据任务中已保存的 script_snapshot 核对。每次手动重新执行使用新的 diagnostic_id，
避免覆盖旧证据。诊断包含家庭隐私，限运维排障使用，不得公开分享；目前沿用私有存储
保留策略，尚未自动按时间清理，生产运维应为 diagnostics 前缀配置合适的保留期限。
任务 manifest 仅保存最近一次执行最多 3 条摘要；回滚失败事务不丢失已经提交的摘要。
诊断写入失败时停止，不继续产生新的分镜请求。

## 页面与历史记录

页面根据错误码显示中文具体原因，不展示模型原始返回、存储地址或内部字段路径。
旧任务没有诊断详情，显示“分镜结果未通过校验”，不再武断地判断为旁白不完整。
无法追溯本次更新以前已经丢弃的模型返回。验证仅使用模拟模型，不自动重试线上失败任务，
不新增用户采访、付费模型调用或视频生成。
