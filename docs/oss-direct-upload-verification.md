# OSS 直传验收（2026-09-10）

## 范围

本次只更新素材上传链路，不修改采访提示词、AI 模型、计费和影像生成。
接口仍复用家庭身份验证、人物归属和素材格式限制。

所有新对象都位于 `LifeReel-Biography/` 根目录下。

## 已验收

- 浏览器通过采访页选择文档、图片、音频和视频四个测试文件。
- 网络记录中有四个浏览器到 OSS 的 POST，零个旧中转上传 POST。
- 后端完成校验并保存四个素材，刷新采访页后可见。
- 浏览器不向 OSS 发送应用 Cookie、API Key 或 AccessKey Secret。
- 实际 OSS 拒绝覆盖现有临时对象，拒绝超过策略大小的文件，拒绝匿名读取。
- 后端实际 SHA-256、分段读取和重复完成请求通过。
- 前端单测覆盖直传、失败不降级、网络错误和关闭直传后的兼容路径。
- 后端单测覆盖四类文件、人物去重、跨人物隔离、跨家庭拒绝、采访绑定、
  超限、伪装图片、元数据不符、过期、缺失对象、并发许可上限和清理失败。
- 浏览器测试主动拦截了后续采访 turn 请求，不产生 AI 调用或扣费。
- 合成测试人物、采访及文件均已删除；未清空已有业务数据。

## 边界

- 浏览器测试使用合成文件，验证上传而非音视频内容生成或播放质量。
- 未执行 2 GiB 文件或 10 人并发负载测试。
- 仍同步读取 OSS 内容进行哈希验证；预览仍走 API。
- 单次 POST 不支持断点续传，许可证有效期一小时。
- Bucket 原有通配来源 CORS 规则保留，正式上线前需人工收紧。
- MinIO 旧素材未迁移，云端流量、存储和请求会按供应商规则计费。
