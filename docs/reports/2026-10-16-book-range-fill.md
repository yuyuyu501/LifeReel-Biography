# 写书年份区间核查与补缺操作

## 问题与改动

第 4、6 章资料中已分别包含“1987—2003年”和“2006—2020年”，旧检查只提取
紧跟“年”的区间末尾年份，把模型正常展开的起始年误判成新增事实。现在对当前事实
和输出统一识别完整年份及区间两端，兼容横线、波浪线、“至”“到”和全角数字。
不自动放行区间内每一年，不从原始引文恢复已更正年份；来源、隐私和事实保护保留。
没有最低、最高或目标字数要求。

页面提供两个独立操作：

- **重新生成全书**：对有可用资料的所有未归档章节安排生成，包含已有稿件的章节。
- **补齐未成稿章节**：只为没有正文且有可用资料的章节安排生成，包含失败空章；
  跳过所有已有正文的章节，包括手写稿、过期稿和失败任务保留的旧稿。

补缺由服务端 `missing_only` 执行；与 `overwrite` 互斥。保持旧 API 默认模式、
旧请求摘要、幂等、版本冲突、来源权限、后台持久任务及计费逻辑。
全书重写保留历史版本，失败不覆盖旧稿。无可补内容时禁用补缺，有任务时禁用生成。

新的校验失败记录结构、引用、空稿、重复段落或事实类别，有限修复提示据此调整，
前端显示对应原因。历史失败记录不改状态，不自动重新调用付费模型。
