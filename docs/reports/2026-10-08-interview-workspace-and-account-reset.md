# 采访双栏界面与账号清理

## 界面变更

采访页直接打开人物对应的 AI 对话和人生资料表，移除“查看以前的采访记录”入口。聊天和资料表采用白底、浅灰用户气泡、正文式 AI 回答、细分隔线与低对比滚动条。两栏独立滚动，输入区域固定在聊天栏底部。

保留文字采访、附件、录音与实时语音入口、资料编辑、修改历史、导出及写书导航。工具使用带名称提示的图标。人物选择同步到链接；文字草稿按会话保存。编辑资料或提交内容时限制切换人物，未发送附件的切换需确认。

## 本地验收

- Web：185 项通过，构建和 lint 通过；两个既有 Fast Refresh 警告未涉及本次改动。
- 浏览器：最终 Docker 镜像上 11 项通过，无未捕获异常。覆盖模拟采访填写、手动修改、历史、表格导出、人物切换、草稿恢复、附件错误、取消切换及加载失败后重试。
- 视觉：1440×900、1920×1080、1024×768 桌面和 390×844 窄屏。检查双栏独立滚动、输入位置和页面边界。
- 清理工具：独立 PostgreSQL 容器内 34 项通过，1 项 Windows 符号链接权限测试跳过。覆盖共享成员、跨租户引用、旧媒体路径、实际删除、钱包清零、保留账号及其他租户、失败事务回滚和媒体备份哈希。
- Docker 数据库迁移版本 `20261008_0044`，`alembic check` 无新增操作。

测试使用隔离数据库、mock 模型及合成资料，没有调用付费模型、短信、支付或真实视频服务。实时语音质量不在本轮验收范围。

## 指定账号清理

用户授权清空 `owner@lifereel.local` 的业务内容，保留账号。预检确认家庭空间由该账号独占，没有待执行任务、冻结余额或其他租户引用。确认 40 个现存 OSS 对象，共 87,412,137 字节。

保留账号密码、登录身份、必要家庭空间关联和空钱包。删除人物、采访及资料表、记忆、书稿、剧本和分镜、素材与成片、照片修复、任务和消费记录；钱包余额及计费余数清零。该账号管理其他用户时产生的其他用户审计记录不属于删除范围。

执行工具为 `deploy/account_cleanup.py`，只在已确认的维护窗口运行。先验证数据库备份，再下载精确归属的 OSS 原件并记录 SHA-256；数据库删除在单一事务中进行，保留表和其他租户内容逐表核对摘要。事务成功后删除已备份的对象并验证 OSS 和该账号缓存为空。

## 发布核验

本地验收后提交并推送 GitHub，服务器获取相同提交。服务器 GitHub 不可达时使用已推送提交的 Git bundle 并校验哈希。

上线前检查任务、保留旧镜像并备份数据库和环境，维护窗口内清理指定账号。随后核验迁移、容器健康、Web 镜像和静态文件哈希、后端运行源码及公网 `/health`、`/ready`。最终提交和执行结果存放在 ignored `tmp/interview-reset-qa/`，服务器备份位于 `/opt/LifeReel-backups/interview-reset-20261008-<提交前12位>/`。

备份中的 `database.dump` 和 `database.sha256` 可用于恢复数据库；`account-cleanup/results.json` 包含对象原路径与备份文件、大小和 SHA-256。业务清空后，这些归档保留在维护备份目录中，不作为在线内容展示。
