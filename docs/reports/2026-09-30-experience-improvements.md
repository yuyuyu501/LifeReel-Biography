# 体验改进验收记录

范围：落实 2026-09-29 体验讨论与实施计划。人物一致性按用户澄清，指同一人物跨镜头保持稳定形象。

## 实现结果

| 反馈 | 本次实现 |
|---|---|
| 错字、转录及事实更正 | 已发送回答可修订，保留原文和版本；版本冲突返回 409，重试使用同一幂等键。原始录音保留。 |
| 纠错后继续沿旧事实采访 | 按回答来源版本重新整理记忆、时间线及剧本；修订排队时过滤旧来源；相关旧冲突标为来源已修订，其他冲突不受影响。 |
| 消息跟随及状态 | 在底部跟随新消息，阅读历史时显示新消息入口；展示真实工作阶段、已等待时间和回应是否就绪。 |
| 换章操作 | 采访页可前后切章和选择目录，复用已有会话；文字草稿按会话保留，附件和录音离开有提示。 |
| 短回答、过早结束、重复问题 | 初稿就绪与采访结束分开；基于最近回答和相关记忆规划少量候选、检查已回答和近似重复；明确暂停/跳过不调用付费整理技能。 |
| 等待时间 | 采访回应先于剧本整理发布并保存检查点；同用户、同模型及工作量至少 5 个样本后才显示耗时范围。 |
| 影像单一及难以局部修改 | 逐镜头预览、相邻描述相似提示、实际视频抽帧、完全重复片段提示；单镜头先报价后重做，其余片段校验哈希后复用，旧成片保留。 |
| 人物跨镜头一致 | 选择固定人物参考照片，各镜头重复使用同一人物参考；官方尾帧仅作补充，不用本地验收抽帧冒充官方参考。 |
| 新用户教学 | 六步教学可收起、恢复及重新打开，只记录步骤和隐藏状态。 |

## 已完成验证

- 后端：732 passed，3 skipped。三个跳过均为 SQLite 下不适用的 PostgreSQL 事务/唯一约束场景；对应 PostgreSQL 分支已执行。
- Web：25 个测试文件，174 项通过，包括修订版本与重试幂等、历史滚动、跨章草稿、教学恢复、局部重做报价、项目级分镜预览。
- PostgreSQL：空库升级、模型一致性、带数据的 0040→0041 升级、默认值、回退及重新升级通过；此前 Schema 迁移回归仍通过。
- Docker：生产 Compose 的隔离项目 lifereel-servicesqa，14 个常驻容器健康；0041 迁移成功，alembic check 无差异。
- Docker 实际 HTTP 联调 12 项：登录、内部接口隔离、任务发布器重启恢复、采访/记忆/剧本/钱包、更正来源与时间线、视频哈希和 Range、记忆服务故障隔离、失败释放冻结款、恢复重试只计费一次、迁移版本和 Schema 分布。
- 模型网关：独立本地模拟 HTTP 服务验证请求重放、连接中断后的不确定状态保护、用量仅送达一次；未调用外部模型。
- 媒体回归：单段重做权限/版本/报价边界、原片保留、复用哈希损坏时在调用模型前失败、只结算新段；真实 ffmpeg 拼接及 JPEG 抽帧解码通过。视频供应商为模拟实现。
- 浏览器：在本地 5189 完成回答 1992→1993 的编辑、排队、同步后剧本更新、展开原文、换章及返回恢复草稿、教学收起恢复、工作台分镜展示检查。验收发现并修复项目级分镜未传入预览的问题。

发布证据原件保存在本机忽略目录 tmp/experience-qa/，不包含在 Git 提交中：api-verified.xml、web-verified.log、e2e-results.json、model-gateway-results.json 及部署核验结果。

## 未覆盖及解释边界

- 未调用付费 AI、短信、支付或真实视频供应商。不能以本轮模拟测试证明真实模型追问自然程度、同音地名澄清效果、视觉丰富度或人物脸型/五官/服装一致性已经验收通过。
- 实时语音的设备权限、通话、人工试听及端到端体验按此前约定跳过。
- 固定参考和提示约束降低形象漂移概率，不保证模型每次严格执行；上线后仍应逐镜头检查人物、声音和衔接。
- 历史镜头与原始成片不会被自动重新生成；旧片资料更新后，重做前核验剧本版本。正常生成失败重试与主动付费重做有各自幂等边界。
- 本轮重点是 Web；小程序原有接口继续兼容，未把新增 Web 交互宣称为小程序端已实现。
- 本轮不新增多机灾备、独立 CDN 或长期容量测试结论。隔离容器隔夜存活不等同于受控长时间压力测试通过。
