# 人生资料表视觉与操作优化

## 界面

保留左侧 AI 采访和右侧人生资料表，采用白底、浅灰工具区、细分隔线和统一无衬线字体。对齐两栏标题高度，保留独立滚动与固定聊天输入区。

资料表使用字段、内容、图标操作的紧凑行布局。常规状态、确定性和来源收进“来源与权限”详情；待澄清、记不清、待整理、内部资料和化名限制保持可见。长内容可展开或收起，完整内容保留。

顶部集中显示版本、处理进度与写书入口。增加“全部／待补充／待确认”筛选和资料分类选择；导出格式和“包含内部资料”选项收进导出菜单，默认不包含内部资料。修改历史、手动编辑和在聊天中补充继续可用，编辑期间锁定筛选与分类。

资料已从服务器加载时显示“资料已保存”，不再要求先出现文字工作流。排队和运行仍显示“正在整理”；失败时显示“整理失败，已有资料已保存”，避免用已保存状态掩盖整理失败。

本次不执行账号清理，保留上一轮清理后新建的资料。

测试使用隔离数据库、mock 模型与合成资料，未调用付费 AI、短信、支付、真实视频或实时语音服务。
