# 账号私密内容与关闭发布

本轮按用户要求撤掉发布授权与分享流程，书籍、书稿及生成影像仅在所属账号空间内访问。

## 实现

- 删除影像页的发布/授权控件、公开播放页面和前端分享 API；首页改为“账号私密”。
- 旧 `/watch/:token` 只显示分享未开放的提示，不请求内容或元数据。
- 后端拒绝所有 audience（含 private）的新发布，不能通过旧客户端或直接请求绕过。
- 历史分享 token 在服务层一律不可用；API 网关同时拒绝公开 token 路径并禁止缓存。
- 移除公开路径的认证豁免。保留数据库历史发布/授权记录和所属账号的撤回接口，
  不删除用户内容，不改变账号余额，不修改现有制作任务的 audience 或计费快照。
- 书籍按签名会话所属 tenant 隔离，页面、正文导出和版本接口都继续校验所属空间。
  生成时的 audience 是制作参数，不构成公开访问许可。

## 验证

- Web 221 项测试通过，涵盖旧链接不拉取内容、影像页不再请求发布/授权服务。
- Web lint 无错误（保留两个原有 Fast Refresh 警告），生产构建通过（保留大包提示）。
- 本次修改文件 Prettier / Ruff 通过，Compose 合成环境校验通过。
- 后端针对生成播放、关闭发布、历史链接与认证、双账号书籍隔离及独立服务的 92 项回归通过。
  双账号使用本地合成用户与签名会话，验证互相看不到列表、不能读取/导出对方书籍，
  伪造 tenant 请求头不能覆盖签名会话；未调用付费供应商或修改生产用户数据。
