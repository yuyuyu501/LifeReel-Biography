# D4 应用阶段基线

本次按用户授权，将实验D4接入资料表应用，作为可运行、可回退的阶段版本。
方法版本为`d4-profile-20261014-v1`，Git标签为`d4-baseline-20261014`。
该版本允许已披露的访谈质量缺口后续修复，不宣称整体访谈验收通过。

## 应用行为

- Lite直接读取原话，输出人物、对象、原子事实、双重出处及访谈策略。
- Sol每轮独立阅读原话，返回完整修正候选；可以补漏、更正、移除和待澄清。
- 程序核验人物、对象、原文引用、本轮来源、同字段旧记录和状态，再适配资料表。
- 家人信息按人物合并，其他重复字段按事件合并，保留原子事实及可读叙述。
- 沿用原有资料版本、幂等、手工确认、更正、隐私、附件上传及工作流失败机制。
- 无明确更正的互斥事件信息保留为争议，不作为有效写作记忆。
- D4不执行旧Lite质量复审，传输失败不自动重发、不保存未经Sol核验的候选。
- 模型网关支持严格结构请求及RPC透传，温度0，最多4096输出tokens。

应用扩展了实验谓词、事件分组和67字段映射。口述资料不会创建上传素材条目。
真实上传仍使用原附件模块。这些产品适配不能直接继承实验组件的量化成绩。

## 真实模型小样本

仅在本地临时数据库创建合成人物，使用实际Lite及Sol接口，总计14次调用，
其中第一次三轮测试的第三轮Sol在120秒读取上限超时，候选未应用。
失败记录独立保留；之后延长Sol读取至240秒，并去除重复发送的字段说明。

新人物三轮复验分别耗时约84、96、110秒，全部完成核验。
最终代码又从第二轮合成资料夹具进行一次更正回合的真实复核，约81秒，
源码摘要在该回合前后保持一致；没有重跑或改写原42案例冻结实验。

| 核对项目 | 结果 |
| --- | --- |
| 本人1970年出生、父亲1940年出生且健在 | 独立记录，未串写身份 |
| 图书馆入职1990年改为1991年 | 更正生效，旧错年份未留在现行工作记录 |
| 修书职责及周师傅教修书 | 保留工作与学习资料 |
| 欠债原因拒谈、整段不进作品 | 原因状态保留，整段内部使用，另记作品排除范围 |
| 纸盒照片尚未上传 | 记待提供，无虚假上传素材 |
| 女儿2019年迁居苏州、每周给本人打电话 | 保存家人及现时联系记录 |
| 明确结束采访 | 不追加追问 |
| 同请求重复提交 | 合成持久化回归中不重复调用、不增加资料版本 |
| Sol超时 | 合成超时回归及真实首次测试均未保存未经核验的事实 |

三轮复验中一条`call_recipient`候选混淆了电话收发方向，程序因`unresolved_object`拦截。
正确的“女儿每周给本人打电话”由另一条`contact_frequency`候选保存；
错误候选及待核对状态仍在审计中。最终代码单回合复核没有候选被拦截。
这说明模型偶发错误仍存在，不能以小样本通过推导所有场景已达标。

第一轮第一次回复包含两个问题，程序保留事实并替换追问；新人物复验的前两轮
自然承接长沙童年和跟师傅修书，未追问欠债原因、未补出创业失败等解释。
这些只属于有限场景观察，长访谈的引导与联想能力仍需按原评定书验收。

原始结果、最终代码摘要及最终模型协议回执保存在忽略目录
`tmp/d4-baseline-20261014/`，不进入Git或生产数据库。
