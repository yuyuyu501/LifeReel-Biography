# 采访资料整理层：首版工程实现与验证

日期：2026-11-05。基线：`56a3abf980310e2bac774323308c5bc76e524fd8`。

## 结论与验收边界

资料整理能力已接入现有 D4/OpenInterviewer 采访流程，新增事实级出处、保守事件关联、按事件限定的更正和有效资料覆盖索引。没有增加模型阶段、第二套事实库、服务 Token、第三方代码或数据库迁移。

工程回归通过不等于真实访谈准确率提高。本轮所有模型响应均为模拟数据，没有调用付费模型，也没有验证真实模型能否准确提取给定句子或自然转场。计划中的六类真实材料对比、真正封存的盲测集和空表人物访谈验收仍未完成。

## 本轮修改

| 修改 | 实际行为 |
| --- | --- |
| `organization.py` | 从当前有效资料派生覆盖和事件引用索引；不调用模型、不写数据库、不生成新的个人事实 |
| 事实级出处 | 每个事实保存核验后的原始来源、版本、引文和位置；重复确认可补充出处 |
| 自动关联 | 仅重复字段、人物/谓词/值/状态相同、共享同一原始出处且唯一匹配时复用条目和事件键 |
| 明确更正 | 在对应事件内替换被更正事实，保留同字段其他阶段；出生年份等少数全局谓词沿用现有全局规则 |
| 覆盖反馈 | 区分未填、已记录、不确定、待澄清、拒谈、记不清、不适用和待续；已记录不代表主题充分 |
| 正文与出处分离 | 事实校验、资料文本、记忆正文和写书选材读取有效事实，排除原子出处元数据，避免旧引用年份混入正文 |
| 发布检查 | 校验运行镜像内整理模块及记忆同步模块的源文件哈希 |

严格关联不会只因“图书馆”“进厂”等关键词相似而合并；歧义匹配、其他人物、手动条目和待澄清资料不自动关联。新的补充事实若没有重复原事实或原始出处，仍需模型正确提供现有 `entry_id/event_key`。这不是完整的语义事件聚类。

每轮使用现有资料与来源目录，不引入新的向量库。`organization.coverage` 覆盖全部当前字段，事件明细沿用现有相关条目选择范围；没有宣称无限上下文、主题充分性评分或自动整理所有历史资料。

历史条目缺少事实级出处时继续兼容旧来源，不猜测回填。原始引文为审计保留，可能包含后来更正的旧说法；有效值及状态优先。既有书稿、剧本和影像不被自动改写，来源变化沿用现有依赖检查与重生成流程。

## 持久化、并发与回归

已验证四轮完整保存：1998 年图书馆入职 → 复述同一经历 → 补充 2005 年离职 → 更正为 1999 年入职。最终只有一条该工作经历，保留岗位事实和离职时间，入职有效值为 1999 年，保留逐事实出处与内部使用范围。每轮重复请求不新增修订或调用模型；历史修订保留旧值，当前记忆正文不含旧年份引用。

还验证父亲迁移的归属、未毕业的否定、不确定年份、拒谈原因、模型返回期间手动编辑的 409 保护、失效引用目录和歧义事件不自动关联。

PostgreSQL 使用独立的本地一次性数据库与 UUID Schema，未连接生产数据。两项验证包括：同时持有同版本的两个写入仅一个成功；写入中途失败使条目和修订一起回滚，重试及重放只写一次。
