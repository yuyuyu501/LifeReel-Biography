# 写书服务验收与发布记录

## 交付范围

新增独立 book 服务与 worker-book、各自 Dockerfile、book Schema 三张表及 0043 迁移。Web 新增“写书”导航、人生书架、章节目录、后台生成、正文编辑、历史版本与整书 TXT/Markdown 导出。

每章目标 1000 字，AI 成稿接受 900–1100 个有效正文字符，不含标点、空白。来源为当前有效记忆，排除私密、争议、旧版本及未解决冲突；素材不足时要求补充采访。来源变更标记旧稿待重写，生成失败保留已有正文。调用沿用现有剧本文字模型、模型网关和文字计费规则。

## 本地验收

- Windows 本地与生产后端镜像内 Linux 全量回归各 775 项，均为 772 通过、3 跳过、0 失败。跳过项是 SQLite 不支持的 PostgreSQL 事务语义；对应 PostgreSQL 分支已执行通过。

- PostgreSQL 迁移专项 6 项通过，覆盖新增书籍表、空库升级、模型一致性、旧数据保留及有书稿时禁止破坏性降级。
- Web 184 项通过，生产构建通过。ESLint 无错误，保留原有两处 Fast Refresh 警告；Ruff 通过。
- 使用生产 Compose 的隔离服务联调 12 项通过：采访→记忆→剧本、对话纠错、媒体生成及哈希/范围读取、Outbox 恢复、故障隔离、退款与任务重试。迁移为 0043，九个业务 Schema、49 张业务表。
- 写书 Docker 联调 5 组通过：目录创建；排队后重启 Worker 恢复并产出 1000 字；更正来源后重写并保留历史；编辑版本冲突、历史和认证导出；钱包 Outbox 仅结算两次不同生成请求、无重复冻结，并记录两条模型用量。
- 浏览器实测确认“写书”导航、书架、章节阅读、版本列表及正文编辑；保存第 4 版后刷新，正文和版本仍存在；实际页面排版正常。
- 模型网关真实 HTTP 联调使用免费合成服务，验证同请求重放只调用一次、断线后不重复调用，以及用量仅投递一次。另有两项年份断言防误报回归通过。

测试证据在本机 `tmp/book-qa/`：`full-linux.xml`、`migrations.xml`、`web-final.log`、`services-e2e.json`、`book-e2e.json` 等。仅使用本机隔离数据库、合成资料和模拟模型，无付费 AI、短信、支付或真实视频调用。
