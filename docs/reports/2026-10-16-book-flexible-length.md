# 写书取消字数门槛

写书篇幅随当前授权事实自然展开，不设目标字数、最低或最高字数。不再把短稿视为失败，
也不为达到原先 900–1100 字范围追加一次模型调用。

## 修改范围

- 提示词不再要求 1000 字，素材不足改按是否存在可用事实判断。
- 取消正文总长、单段长度和段落数量门槛；正文编辑同步取消原 12000 字上限。
- 实际字数仍记录和显示。保留空稿、纯标点段落、重复段落、来源和既有事实校验，
  以及隐私、当前资料、版本并发、历史稿件与计费保护。
- 旧 `target_words` 字段与来源快照保留兼容，但不传给模型、不新增到计费快照。
  既有来源摘要不变，旧稿不会仅因本次规则调整被标记过期。
- 清理页面目标篇幅及字数失败提示，修正小屏目录与正文被挤在两列的问题。

## 验证

- 写书回归 46 项通过；资料选材、资料表和模型池回归另 50 项通过。
- 发布脚本和架构检查 6 项通过；后端 Ruff、wheel 打包和生产 Compose 校验通过。
- Web 全量 206 项通过，lint 无错误，构建及修改文件格式检查通过。
  保留原有两处 Fast Refresh 警告及大 JS chunk 警告。
- 短稿和超过原上限的长稿均一次模型响应完成发布，实际计数、手改、导出和一笔结算正常；
  空稿、纯标点、重复段落、错误引用、无依据年份继续被拒绝。
- 本地浏览器覆盖桌面和手机阅读、目录文案、空章、失败保留旧稿，以及 15000 字正文保存重开。
  全部为合成响应，无真实模型调用。

已缓存的真实模型输出复验：859 字稿通过；841 字稿不再被字数拦截，但仍触发现有年份检查。
资料中的“1938—2016年”“1941—2020年”只被旧正则识别到末尾年份，正文展开成出生年时会误拦。
这是独立的年份格式兼容问题，本次保留事实检查，不将两份稿件都宣称为验收通过。

本轮不自动重发历史失败任务、不覆盖旧稿、不补扣费用。供应商上下文、输出 token 和输入预算
等技术限制仍然存在；取消篇幅门槛不代表模型能无限输出或保证每次事实与文学质量。
