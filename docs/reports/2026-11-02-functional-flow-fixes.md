# 首页与跨端功能流程修正

## 改动范围

- 移除首页“工作动态”模块及对应样式。没有实际回答的采访不计入记录；
  “继续上次采访”选择最近更新且未完成的资料采访。空目录不再显示为已有书稿，
  素材数量也不再代表记忆整理完成。
- 完成影像后可填写授权人、明确确认分享范围再发布。未成年人显示监护人授权。
  支持查看真实分享链接、撤回发布、管理和二次确认撤销授权。
  授权保存成功但发布失败时，重试复用已保存授权。
- 公共元数据与视频请求都重新检查发布时已存在的有效授权，并禁止缓存响应。
  授权撤销或过期后，没有其他原有有效授权覆盖的链接停止新访问；
  后续重新授权不能恢复旧链接，必须重新发布。授权重叠时保留仍被覆盖的链接。
  列表或公开访问会同步撤回状态，身份服务不直接修改媒体服务的表。
- 小程序登录增加“绑定已有网页账号”，通过原手机号/邮箱、密码与平台临时登录码
  绑定同一个用户和家庭空间，复用原家人、书稿及钱包；已关联其他账号的身份拒绝迁移。
  不自动合并两个空间。切换模式及成功登录时清空密码。
- 小程序刷新凭证检查用户当前会话版本；改密、停用或删除用户后不能借助旧刷新凭证续期。
  绑定时在平台换码后加锁重查密码及账号状态。
- PostgreSQL 针对性回归发现的时区比较问题一并修正：保留已有时区，
  只对无时区的 SQLite 时间补 UTC，避免授权、验证码或刷新凭证延后过期。

撤回只能停止后续请求，不能收回已下载或已经载入的副本。

微信 AppID 已在本地配置，抖音 AppID 尚未配置。上述小程序验证仅涵盖构建和 H5
交互，不代替开发者工具、平台换码、真机登录、上传或平台审核。
H5 绑定操作明确提示使用小程序真机，不会将输入凭证发送到账号服务。
服务器部署也不会自动发布小程序客户端。
