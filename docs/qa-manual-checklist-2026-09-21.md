## 已修复缺陷的原始复现步骤

以下描述保留修复前现象，用于之后发布验收。F01/F02/F03 均已在当前工作区修复，相关回归通过；原有运行容器尚未更新。完整原始位置与证据见 [测试报告](qa-report-2026-09-21.md)。

- **F01：数据库外键缺失。** 在独立空 PostgreSQL 库执行迁移至 head 后运行 `alembic check`，修复前报告三个缺失外键；修复后应无差异且删除父记录会置空引用。
- **F02：纯语音剧本显示未同步。** 新章节仅使用实时语音，等待知识/剧本更新后挂断并刷新；已有剧本仍显示“最新内容尚未同步”。不要为了验证而反复点击付费重生成。
- **F03：人物必填字段 null 返回 500。** 仅对测试人物，以已认证请求分别 PATCH `display_name`、`is_subject`、`is_minor` 为 null，修复前为 500，修复后应为 422；随后读取原人物确认字段未改变。

如需线上发布修复，仍应遵守项目顺序：本地修改和验证 → 提交推送 → 服务器获取同一提交 → 检查活动任务、备份和回滚镜像 → 迁移和部署 → 验证运行容器、健康状态与提交一致。本次测试没有执行发布。
