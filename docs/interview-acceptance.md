# 人生访谈与记录评定书

版本：1.0，2026-10-13。冻结于本轮 Lite / GPT-6.1-Sol 实测之前。

## 什么是好的访谈

帮助讲述者自愿讲出具体、真实、有个人意义的经历。引导是邀请回忆、澄清和展开，不能诱使讲述者接受 AI 编造的答案。表格填满、回复好听或任务显示成功都不等于访谈合格。

优先级：用户意愿与隐私、事实可靠、有效引导、话题联想、交互速度。

## 评分锚点

每项按 0 到 5 分评定。0：严重错误或完全缺失；1：经常失效；2：偶有作用但主要依靠讲述者补救；3：基本可用，存在明显重复或遗漏；4：稳定有效，只有轻微问题；5：自然准确，并能处理困难情况。评分必须列出回合编号、原话和具体证据。没有观察机会的项目记为未测，不填满分。

| 能力 | 权重 | 4 分应达到的表现 |
| --- | ---: | --- |
| 倾听承接 | 10 | 承接刚说的具体人物、动作、感受或影响；不套空泛赞美 |
| 有效追问 | 10 | 一个清楚、容易回答的主要问题；能得到新细节，避免重问已知信息 |
| 访谈推进 | 10 | 故事有经过及影响后适时转题；不反复追问微小动作，不强迫填表 |
| 有依据的联想 | 10 | 从人物、技能或生活变化连接相关方向；没有新增个人事实预设 |
| 联想的实际收益 | 10 | 联想得到新的有效叙述；公共背景和个人经历分开，检索失败如实处理 |
| 事实记录 | 20 | 把已披露事实完整、准确地保存；人物、时间、行为、因果归属正确 |
| 字段与持续记忆 | 10 | 字段归类正确，同一事件不重复；补充不覆盖旧信息，暂停后可继续 |
| 出处与纠正 | 10 | 原话及消息版本可追溯；不确定和冲突不冒充已确认，更正关联记录 |
| 意愿、隐私与可靠性 | 10 | 尊重拒绝、暂停和结束；限制作品使用范围；失败可见且不伪装成功 |

总分 = 各项分数 / 5 × 权重。访谈分单列前三项 / 30，联想分单列两项 / 20，记录分单列三项 / 40。由程序产生的暂停句、澄清句及回退句不计为模型引导成功。AI 主动追问得到的新事实与测试者主动补充的事实分别统计。

## 记录质量的可计算指标

原子事实是可以单独判断真假的最小陈述，例如“1986 年进修理厂”和“师傅姓吴”是两条。身份、行动、时间、原因、动机、感受均须有独立依据。评分时先逐条拆分保存结果，再与已经披露的用户原话核对；不能用关键词出现或同模型自评代替语义核对。

- 已披露事实召回率 = 最终有效资料中准确保留的不同事实 / 已向 AI 披露的有效事实。人物种子字段、隐藏人设和后来明确撤回的旧事实不进入分母。失败回合已经收到的回答仍进入分母。
- 事实准确率 = 有原话支持且归属正确的保存原子事实 / 全部保存原子事实。重复不增加正确事实数；无依据、错归属、已纠正旧值仍作为有效值均为错误。
- 正确字段召回率 = 保存在规定字段的事实与字段配对 / 预先定义的有效配对。仅在别列出现不算归类成功；同一事实可合理支持多个字段，配对在测试前固定。
- 出处完整率 = 可追溯至正确用户消息版本、且原话支持该事实的条目 / 应有用户出处的条目。连续原话存在只是必要条件。
- 保留率 = 补充、纠正、暂停或恢复后仍保留的应保留事实 / 操作前应保留事实。更正涉及的旧值允许退出有效资料，历史必须保留。
- 重复率 = 同一字段同一事件的多余有效条目 / 全部有效条目。相似文字须人工核对，不能只按字符串判重。

不适用、拒答、未知、待续以及未上传素材均为合法结果。没有上传的照片不得记为已上传资产。逐一检查 67 个字段，不能把合法空白计成遗漏。物理照片的口述可以保存到待提供说明。

## 硬性验收门槛

以下各项同时通过，才可标记本轮“达到合成访谈验收标准”。单套人设通过不代表所有真实用户均可达到相同效果。

| 项目 | 门槛 |
| --- | --- |
| 总分 | 至少 85 / 100 |
| 访谈与联想 | 每个已测维度至少 4 / 5；未测项不能视为通过 |
| 已披露事实召回率 | 至少 90% |
| 事实准确率 | 至少 98% |
| 正确字段召回率 | 至少 95% |
| 出处完整率、应保留事实保留率 | 100% |
| 重复率 | 不超过 2% |
| 严重个人事实编造、跨人物身份串写、假称检索 | 0 次 |
| 拒绝、隐私、暂停、恢复、结束、冲突、明确纠正 | 所有专门案例通过 |
| 首次提交完成率 | 至少 98%；每次失败和重试都保留 |
| 普通回合端到端耗时 | P95 不超过 30 秒；沿用前轮完整访谈门槛 |

检索轮另列 P50/P95、失败率和来源支持情况，不混入普通轮掩盖长尾。速度从提交开始量到审核后回复和资料持久化完成；当前非流式流程没有可报告的首字速度。调用数和供应商 token 用量单列，未知单价不编造人民币成本。更强模型通过更长超时完成，不等于产品延迟通过。

## 公平对照协议

1. 先冻结本文件、人设、原子事实、字段配对、边界案例和代码摘要，再调用真实渠道。评分规则不能看完结果后放宽。
2. 同一代码、提示词、温度、超时、审核策略和工具资料，仅切换主模型及对应渠道。单模型比较中，生成和审核均由该模型承担，关闭跨模型升级；因此成绩是“该模型加当前应用链路”的效果，不是裸模型排行榜。
3. 使用新增家人的正常 API，只给称呼，不手工填表。两个模型使用独立新数据库，第二轮开始时资料、会话、缓存及用量均为空。完整金标准不能送给被测模型。
4. 记录轨：同一组逐轮披露材料，覆盖 67 字段及困难场景。测试者主动转题或补充标记为主动，不把该轨填表成功冒充引导成功。
5. 引导轨：同一隐藏人设、同一句开场和相同回合预算；测试者按实际问题回答，只回答被问内容，不因某模型弱而额外送信息。提前固定访谈目标和允许披露的事实；未知事项如实说不记得。
6. 主比较使用同一份可复现公共历史摘录；另做真实检索检查。真实网络结果不稳定的成绩不可直接归因于主模型。
7. 保存所有请求结果、失败、延迟、用量、每轮资料快照和最终出处。人工核对全部保存原子事实、纠正与边界回合；逐回合评价 AI 追问，保留评分依据。
8. 如修复应用或提示词，旧成绩保留，双方在同一新版本重新测试。只补测弱模型后与另一模型旧成绩比较无效。最终验收增加一个未参与修复的人物，防止对单个人设拟合。
