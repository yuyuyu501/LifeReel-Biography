# ADR 0001：采用模块化单体与独立 Worker

- 状态：Accepted
- 日期：2026-08-28

## 背景

采访、长期记忆和剧本共享人物、证据、主张与版本事务。项目早期团队规模和流量尚不足以承担微服务的分布式一致性与运维成本，但 ASR、视频生成和合成属于长耗时、高失败率任务。

## 决策

API 采用 FastAPI 模块化单体；长任务进入 Redis 队列，由独立 Worker 执行。数据库以 PostgreSQL 为事实源，对象媒体进入私有 S3/MinIO。

## 后果

- 领域模块必须保持单向依赖，不允许路由文件承载业务逻辑。
- Production/Media 可在规模增长后优先拆分。
- 所有长任务必须具备状态、幂等和可恢复能力。
