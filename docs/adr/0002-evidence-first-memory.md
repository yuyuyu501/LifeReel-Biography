# ADR 0002：证据优先的长期记忆

- 状态：Accepted
- 日期：2026-08-28

## 背景

口述史内容存在记忆误差、多人说法冲突和 AI 幻觉风险。若直接把模型整理后的文章当作事实，后续采访、剧本和视频会放大错误。

## 决策

原始媒体、逐字稿片段和用户校对版构成证据层；结构化事实以 `Claim` 存储，并关联来源、时间定位、置信度、敏感度和状态。更正通过追加新版本或撤回关系完成，不静默覆盖。

## 后果

- 没有来源的事实不能进入锁定剧本。
- 冲突说法可以同时存在，并生成温和的后续确认问题。
- 用户删除或撤回来源时，相关主张和生成作品能够被追踪。
