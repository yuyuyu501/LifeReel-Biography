# ADR 0003：AI 与媒体供应商必须可替换

- 状态：Accepted
- 日期：2026-08-28

## 背景

ASR、LLM、图像、视频和语音模型的价格、能力、地区和政策变化频繁。将厂商 SDK 写入业务逻辑会提高迁移成本并造成数据模型被供应商参数污染。

## 决策

所有外部模型通过内部 Provider 协议接入；业务任务只保存内部标准请求和结果。适配器负责请求转换、回调验签、错误归一化、成本解析和输出下载。

## 后果

- 每个 Provider 必须有契约测试。
- 业务层不直接引用具体厂商 SDK。
- MVP 使用 Mock Provider 跑通无付费的完整状态机。
