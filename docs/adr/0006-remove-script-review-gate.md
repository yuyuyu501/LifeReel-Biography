# ADR 0006：移除剧本审核门槛

## 状态

已采纳，取代 ADR 0004 中“审核后锁定章节”的决定。

## 背景

采访与剧本现在是同一个实时工作流：每次回答或素材上传都会补充记忆，并重新整理当前章节。章节审核会锁住稿件，使后续采访无法继续优化内容；同时，记忆档案已经改为只读展示，不再承担人工审核台职责。

## 决策

- 用户界面不再显示剧本通过、驳回、批量选择、待审核状态或审核提醒。
- 移除剧本审核 API；新增采访可以持续替换同一章节的当前稿。
- 视频生产不检查剧本审核状态，只要求剧本至少包含一个章节，并满足制作、肖像及必要的监护人授权。
- 发布仍要求发布授权，发布范围必须与制作范围一致，且支持随时撤回。
- 数据库中的旧审核字段暂时保留，用于兼容已有数据和迁移历史，但不再进入 API 契约或业务判断。

## 结果

采访到剧本的反馈循环不会被人工状态中断；法律与隐私边界继续由独立授权模块保障。
