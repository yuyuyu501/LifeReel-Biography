# ADR 0019: shadcn/ui 前端设计系统

日期：2026-09-16

## 目标与边界

统一岁忆影传工作台的视觉与交互，沿用现有 React 19 / Vite 应用，不替换业务路由、API、AI 工作流、计费或认证逻辑。
本 ADR 的组件与色彩约定覆盖原设计系统中相冲突的示例代码，不改变书籍入口、双栏采访和分组导航的产品约定。

## 实现

1. 引入 Tailwind CSS 4、官方 shadcn/ui New York 组件源码、Radix、CVA 与 class 合并工具。配置 components.json 和 @ 路径别名，保留 MIT 许可。
2. 在 global.css 定义中性灰白底、墨色正文与品牌绿的语义变量；浅色侧栏按生命档案流程、个人资料、平台管理分组。
3. 页面模块进入 components 级联层。清除重复的按钮和废弃弹窗样式，保持子页面样式位于父页面末尾的组织方式。
4. 实际迁移全站通用操作、链接按钮、表单输入、剧本编辑输入、账号与人物弹窗、支付弹窗；增加账户菜单、焦点提示和加载骨架。
5. 登录、注册与找回密码共用紧凑单栏表单。书籍入口保留；章节详情移除大面积深色头部和重投影。采访保留独立滚动与显式录音、素材、发送入口。
6. 账号和人物弹窗保存中不可关闭；支付弹窗关闭不改变订单或余额。价格、支付核实方式、短信模板与限流均保持原逻辑。

## 可访问性与适配

- 标准按钮、图标按钮及输入框默认 44px；原生文件输入、下拉选择与复选框保持浏览器行为。
- Dialog 支持 Escape、焦点约束、背景隔离和关闭后焦点恢复；忙碌状态保护正在提交的表单。
- 手机底部导航预留安全区，保留个人资料快捷入口；桌面账号菜单支持键盘。
- 删除外部字体请求，保留本地中文字体回退；遵守 reduced-motion。
- 本轮只交付浅色主题，不承诺深色模式。

## 验证

- 前端单元与组件回归：129 项，包括新增原生表单语义、asChild 链接、密码管理器属性、弹窗焦点恢复与忙碌状态保护。
- 本地真实 API 的只读浏览器检查：主要 9 个页面，1440 / 768 / 390 / 320px；登录、注册、找回密码及人物弹窗、账户菜单。
- 模拟 API 检查：采访、剧本和影像的四元素、章节隔离、编辑保存、采访重新生成、独立滚动、手机标签切换。请求全部拦截，不触发真实 AI 或扣费。
- 生产构建和 lint；发布后检查公网页面、静态资源和现有健康接口。

## 维护

控件行为改在 components/ui 或有业务语义的包装组件，页面布局改所属 CSS 模块。
禁止引入一整套后台模板覆盖现有路由；不在样式入口末尾叠加页面修补规则。
UI 依赖单独构建为可缓存的 vendor chunk。发布只替换 web 镜像，不迁移数据库、不重启 AI worker。
