# 书籍导入接口

`POST /v1/books/import`，登录账号需有编辑权限。请求为 `multipart/form-data`：

| 字段 | 类型 | 要求 |
| --- | --- | --- |
| subject_id | UUID 字符串 | 必填，当前账号拥有的人物 |
| title | 字符串 | 可选，去掉首尾空白后 1–180 字符；覆盖文件中的书名 |
| file | 文件 | 必填，扩展名 `.txt`、`.md` 或 `.markdown`；UTF-8，可含 BOM |

成功返回 HTTP 201，JSON 为现有 `Book`（含目录及 `current` 正文版本）。
响应可直接打开 `/books/{id}`，后续编辑、版本记录和 TXT/Markdown 导出使用原接口。
共享类型见 `packages/contracts/src/book.ts` 的 `BookImportFields` 和导入限制常量。

## 文件规则

- 最大 2 MiB（2,097,152 字节）；最多 40 章，书名及章节标题最多 180 字符。
- 接受本系统导出的结构：第一行书名，空行，`目录`，连续编号的目录项，空行后为章节。
- Markdown 的书名为 `# 书名`，章标题为 `## 标题`；正文中的三级及以下标题保留。
- 新 TXT 导出的正文章标题为 `【第1章】正文标题`，章号对应目录编号，保留与目录不同的正文标题。
  正文中与目录同名的独立段落不再被误当作章节；未成稿章保留原目录位置。
- 兼容旧 TXT：先按唯一的目录同名标题定位；标题不同时，仅在独立标题候选数量与已成稿章节数
  完全一致、顺序与已知目录标题相符时按顺序恢复。旧格式候选须单独成段、不超过 180 字符，
  且不含句号、问号、叹号或分号。无法区分标题与正文时仍拒绝，避免错分或丢失正文。
- 保留目录顺序及“（未成稿）”空章，至少有一章非空正文。
- “（资料已更新，待重写）”为原导出状态标记，不属于目录标题；
  导入只恢复文本，不恢复原账号资料引用、授权、任务或核查结论。
- 拒绝乱码、二进制控制字符、空文件、目录不连续、章节缺失、多余章节或无法唯一解析的格式。
- 正文换行统一为 LF，去掉正文首尾空行，内部段落保留。可选 title 只覆盖书名。

## 约束与错误

标准错误结构：`{"error":{"code":"...", ...}}`。

| HTTP | code | 含义 |
| --- | --- | --- |
| 401 / 403 | 现有认证错误码 | 未登录或只读权限 |
| 404 | SUBJECT_NOT_FOUND | 人物不存在或不属于当前账号 |
| 409 | BOOK_ALREADY_EXISTS | 该人物已有书籍（即使未成稿），不覆盖、不合并 |
| 409 | BOOK_GENERATION_BUSY | 该人物正在被其他创建或导入操作锁定，可稍后重试 |
| 413 | BOOK_IMPORT_TOO_LARGE | 文件超过上限 |
| 422 | BOOK_IMPORT_EMPTY | 文件为空或仅空白 |
| 422 | BOOK_IMPORT_ENCODING_INVALID | 非 UTF-8 |
| 422 | BOOK_IMPORT_FORMAT_INVALID | 扩展名、控制字符、目录或正文结构不合法 |
| 422 | REQUEST_VALIDATION_FAILED | 缺字段、UUID 或 title 不合法 |

同一人物只允许一本书；重复提交返回冲突，不会重复写入。
文件先完整校验再写入；书籍、章节和人工版本在一个数据库事务中保存，失败整体回滚。
导入章节使用自有目录和人工版本（`author=user`，无模型名及事实引用）。
导入不会创建付费任务或扣费。后续 AI 写作仍要求用户另行选取获准资料。
不需要数据库迁移。
