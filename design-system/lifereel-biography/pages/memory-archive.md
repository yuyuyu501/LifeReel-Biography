# 记忆档案页

本页覆盖 `MASTER.md` 中旧的“长期记忆审核台”定义。

## 页面职责

- 以单个人物为边界，只读展示采访沉淀的个人小传、关系图谱、事件时间线和回忆文件。
- 文件只能从对应人物的采访聊天中新增；本页不提供上传、转写编辑、AI 分析或记忆审核操作。
- `/evidence` 作为历史地址重定向到 `/memories`，主导航不再出现独立“素材”步骤。

## 信息结构

1. 人物选择与人物小传。
2. 档案统计。
3. 以主人公为中心的关系图谱，以及等价的键盘可操作关系索引。
4. 来自采访原话的人生事件时间线。
5. 图片、文档、音频、视频四类只读文件浏览器。
6. 仅在存在冲突时展示冲突提示。

## 图谱规则

- 主人公固定在中心，人物、地点、组织、事件使用不同颜色和形状。
- 关系名称和事件均来自有效 `MemoryClaim`；`private` 与 `disputed` 主张不得进入图谱。
- 每个节点和边保留 `source_claim_ids`，选中后展示支撑关系的采访原话。
- 不根据模糊语句推断家庭关系；无法确认时只标记“相关人物”“相关地点”或“相关组织”。
- 图谱使用确定性布局，人物切换时完整重算；移动端改为单栏，不能出现横向溢出。

## 视觉与交互

- 沿用冷白纸张、档案绿和克制朱红，不新增渐变或装饰性卡片。
- 图谱是本页唯一强调性的交互工具，其余区域保持档案索引式排版。
- 节点支持点击、Enter 和空格选择；关系索引提供不依赖图形识别的等价入口。
- 图片延迟加载；音视频使用原生控制；文档在内嵌预览之外提供新窗口打开入口。
