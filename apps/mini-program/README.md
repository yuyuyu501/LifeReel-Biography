# 小程序：查看界面、测试与发布

## 先在本机看到界面

在项目根目录 `E:\LifeReel-Biography` 执行：

```powershell
pnpm install --frozen-lockfile
pnpm --filter @lifereel/mini-program dev:preview
```

浏览器打开 `http://127.0.0.1:5175`。首页、登录、采访、记忆、剧本和视频任务复用小程序页面代码。页面顶部始终标明“本地模拟数据”；数据仅存于页面内存，刷新后恢复示例。预览不会连接线上 API，不会调用 AI、短信、支付或真实视频生成。录音按钮会说明需真机测试。

浏览器预览用于查看布局、文字、入口和操作反馈，不代表已通过微信/抖音运行时或真机测试，也不是已发布的小程序。

## 原生开发工具准备

### 微信尚未注册时

本项目已提供本地预览，不需要先注册才能看界面。要在微信手机端运行自己的小程序，则需要先有真实小程序账号。

1. 在电脑打开微信公众平台 `https://mp.weixin.qq.com/`，点击右上角“立即注册”。
2. 在账号类型中选择“小程序”。官方当前页面单独列出了公众号、服务号、小程序。
3. 按页面向导设置登录账号并完成验证。准备一个由你长期管理、符合该页面注册条件的邮箱。
4. 按实际持有的营业执照填写企业主体。结合现有业务，建议以“广州易森信息科技有限公司”申请；法定主体名称、统一社会信用代码及其他资料以营业执照和平台要求为准。
5. 按向导完成管理员绑定和身份/主体核验。相关扫码、验证码、实名和企业验证由你本人或有权管理员操作，不把这些凭证发进聊天或写入代码。认证费用与核验方式以当前页面为准。
6. 注册完成后进入该小程序后台的开发管理/开发设置，查找 AppID。AppID 可用于开发工具配置；AppSecret 是另外的服务端凭据。
7. 补齐小程序名称、图标、介绍、实际服务类目、隐私声明，以及平台当前要求的备案和资质；是否可预览、提审及发布，以后台检查结果为准。

抖音需在其开放平台另行注册开发者并创建小程序，微信账号及 AppID 不能直接复用。注册、获得 AppID、真机预览、审核通过和正式发布不是同一件事。

### 已有账号后的配置

1. 分别在微信公众平台、抖音开放平台创建小程序，完成平台要求的主体、类目及身份资料。现有网站部署不会自动创建小程序。
2. 获取两个小程序各自的 AppID，并把登录开发工具的账号加入对应开发者列表。微信 AppID 与抖音 AppID 不通用。
3. 安装微信开发者工具、抖音开发者工具，分别用有权限的账号登录。
4. 复制本目录 `.env.example` 为 `.env.local`，填写 `WECHAT_APP_ID`、`DOUYIN_APP_ID`；API 地址默认 `https://bianjiaigc.com`。AppSecret 只在服务器配置，不要写进客户端。
5. 服务器配置对应平台真实登录凭据；平台管理后台配置 request/uploadFile/downloadFile 等实际用到的合法域名及隐私声明。API 域名与媒体实际访问域名要分别核实，不能以开发工具中忽略域名校验代替验收。

## 微信开发工具导入

```powershell
pnpm --filter @lifereel/mini-program build:weapp
```

在微信开发者工具选择“导入项目”，目录选择：

```text
E:\LifeReel-Biography\apps\mini-program\dist\weapp
```

构建会生成 `project.config.json` 和六个页面；AppID 从本地配置读取。使用已有后端服务，不需要新建云开发环境。未配置 AppID 时脚本明确提示，不能把空 AppID 包当成可上传版本。修改代码时可用 `pnpm --filter @lifereel/mini-program dev:weapp` 自动重新编译。

编译运行后先看模拟器，再点开发工具“预览”并用有权限的微信扫码。上传代码后，在微信公众平台版本管理中设置体验版、添加体验成员。验收通过后才提交审核；审核通过后执行发布。审核通过和正式发布是两个状态。

## 抖音开发工具导入

```powershell
pnpm --filter @lifereel/mini-program build:tt
```

在抖音开发者工具导入：

```text
E:\LifeReel-Biography\apps\mini-program\dist\tt
```

抖音源码配置为 `project.tt.json`，Taro 会在上述输出目录生成开发工具需要的 `project.config.json`。使用抖音的 AppID，确认请求域名配置后查看模拟器。修改代码可用 `pnpm --filter @lifereel/mini-program dev:tt`。

在开发工具预览/真机调试，使用有权限的抖音账号扫码。之后上传代码，在抖音开放平台版本管理中配置测试/体验成员并进行体验验证，再按平台流程提审、审核通过后发布。具体入口名称以当前平台控制台为准。

两端输出目录独立，连续构建不会相互覆盖。不要导入源码目录或旧的 `dist` 根目录；也不要把 H5 预览目录上传到任一平台。

## 真机验收清单

- 首次登录、退出、重新登录与会话过期；账号和人物归属正确。
- 人物创建/切换，六个页面的布局、滚动、键盘遮挡和返回。
- 文字采访、知识/时间线/剧本展示、刷新后读取已保存内容。
- 录音授权同意/拒绝、停止、上传、失败重试；前后台切换。
- 媒体访问、播放与网络切换；页面关闭后重新查看任务状态。
- 支付入口保持未开放；实时语音不纳入本期。

真实 AI/视频生成会产生费用，不能作为日常发布检查自动执行；需另行安排已授权的真实模型测试。浏览器模拟数据通过不能勾选这些真机/生产联调项目。

## 发布与回滚的区别

API/Web 按仓库的本地测试→提交推送→服务器更新部署流程发布。小程序客户端则在 Git 提交与构建验证后，分别上传到微信和抖音平台，再走体验、审核和发布；只更新服务器不会让小程序在手机上出现。

本次预览与导入配置无需修改数据库或重启生产服务。上传前核对 Git commit、构建目录、真实 AppID、后端域名、隐私声明和成员权限。平台审核/发布尚未操作，不应写成已经上线。
