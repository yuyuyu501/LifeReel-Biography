# 样式组织

`../styles.css` 只作为统一入口，按全局、公共组件、页面的顺序加载。
保留全局类名，不引入 CSS Modules 或级联层，避免改变现有组件和选择器优先级。

| 文件                | 职责                                                 |
| ------------------- | ---------------------------------------------------- |
| `global.css`        | 字体、设计变量、基础元素、无障碍、动画与减少动态效果 |
| `layout.css`        | 应用外壳、导航、工作区、页面容器                     |
| `components.css`    | 标题、按钮、表单、弹窗、提示、空状态、价格说明       |
| `asset-preview.css` | 图片、音频、视频、文档的公共预览组件                 |
| `home.css`          | 首页概览与工作动态                                   |
| `people.css`        | 家人列表与人物卡片                                   |
| `interviews.css`    | 采访目录；文件末尾为采访工作台、聊天与实时剧本       |
| `memories.css`      | 人物介绍、知识图谱、时间线、回忆文件                 |
| `scripts.css`       | 家庭书架；文件末尾为书籍详情、章节生成器、目录与正文 |
| `studio.css`        | 影像目录、播放器、剧本文本与发布区域                 |
| `wallet.css`        | 余额、在线充值与消费明细                             |
| `login.css`         | 登录与注册                                           |
| `public-reel.css`   | 公开影像播放页                                       |

## 修改约定

- 全局变量只放在 `global.css`；共享控件放公共组件文件，页面专属规则放所属页面。
- 每个页面先写基础样式，再写该页面的媒体查询；子页紧接在父页面全部样式之后，同样先基础、后响应式。
- 同一区域的相同断点合并，按宽到窄排列；不要重新在入口或文件末尾追加混杂的覆盖规则。
- 注意相同优先级的跨模块覆盖。采访页面宽度、页面标题对齐及影像页面顶部间距保留了原有断点行为。
- 删除规则前同时检查静态和动态类名，例如 `book-tone-${index % 3}`、`is-${asset.kind}`、任务状态和录音状态；不能只按当前页面是否可见判断。
- `asset-preview.css` 是共享组件，不属于已停用的 `/evidence` 页面；不要随旧上传页一起删除。
- 样式按多行格式保存，用 Prettier 格式化。CSS 行数会增加，评估冗余应看有效规则与构建产物体积。
