# LifeReel API

FastAPI 模块化单体。当前包含：

- 本地账号、HttpOnly 会话、租户成员与角色权限
- 人物档案、未成年人和监护授权
- 11 个自传章节、规则/LLM 自适应追问
- 私密证据、OpenAI-compatible ASR、逐字稿版本
- 来源化长期记忆、实体、时间线、冲突与覆盖率
- 单章/多章短视频剧本、场景、镜头与持续更新
- Redis 任务账本、Mock FFmpeg 与通用异步视频 Provider
- 分受众发布、令牌观看、撤回与审计
- PostgreSQL/Alembic 与 SQLite 测试模式

运行方式见仓库根目录 README。
